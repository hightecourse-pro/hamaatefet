## 1. כניסה והרשמה (Main)

- מסך אחד עם לשוניות **כניסה / הרשמה**, מצבי "המעטפה בדרך", "שכחתי סיסמה", "בדקי את תיבת המייל".
- הרשמה (הכניסה הראשונה) אוספת: **שם פרטי, שם משפחה, מייל, טלפון, סיסמה (8+), חודש לידה עברי, אישור גיל 30+, אישור תקנון**. כל שדה חובה; שגיאות בעברית.
- אחרי הרשמה: מייל אימות (שולח: "חד או פאן") → קישור ל-`/auth/confirm` → מסך "ממתינה לאישור". הצוות מקבל מייל "מישהי דופקת על המעטפה".
- מייל שכבר קיים: הודעה ידידותית, בלי יצירת חשבון כפול.
- כניסה: שגיאת סיסמה → "המייל או הסיסמה לא נכונים"; מייל לא מאומת → הסבר. "זכרי אותי" מבוטל = יציאה אוטומטית אחרי 8 שעות.
- שכחתי סיסמה: קישור תקף לשעה → `/reset-password` (סיסמה חדשה פעמיים).
- כתובות מוגנות (`/home`, `/forum`, `/millionaire`, `/birthday`, `/profile`, `/admin`) מפנות ל-`/login` כשלא מחוברת.
- חברה ממתינה/מושהית → `/pending` בלבד. חברה שחסרים לה פרטים → `/welcome` עד שתשלים.
- חברה רגילה ב-`/admin` → מופנית ל-`/home`.

## 2. תפריט ראשי (Home)

- ברכה בשם פרטי, שלוש מעטפות (הפורום / המיליונרית / חוגגות חודש טוב) עם תגי המדורים מה-DB.
- פס "המפגש הקרוב": המפגש המפורסם הקרוב ביותר (כל סוג), תאריך עברי, שעות, מקום, מחיר, כפתור **אני באה!** ⇄ **נרשמת! (ביטול)**. מלא → "המקומות נגמרו".

## 3. הפורום

- מדורים מה-DB (+ "הכל"), סינון בכתובת (`?section=`), חיפוש (`?q=`), "חדש!" על מדורים חדשים.
- פיד: הכי חדש למעלה, מוצמדים ראשונים. כרטיס: אות ראשונה, שם, "לפני כמה זמן", תג מדור, כותרת (עזרה הדדית: "מבקשת:"/"מציעה:"), גוף, תמונה (חתומה לשעה), **אהבתי** (מונה), כפתור תגובות לפי מדור ("להצטרף לדיון" / "אני יכולה לעזור" / "אשמח!" / "להגיב").
- פוסט חדש: מדור (כולל עזרה הדדית – מבקשת/מציעה), כותרת (עד 140), גוף, תמונה (עד 5MB). עם "אישור צוות" דולק → הפוסט ממתין ורק הכותבת רואה אותו עם תג.
- מחיקת פוסט/תגובה: רק של עצמה (או צוות).

## 4. המיליונרית

- Hero עם הצ׳ק, "איך זה עובד", **המארחות הבאות** (מפגשי אירוח מפורסמים מהיום והלאה) עם "שמרי לי מקום" ⇄ "נרשמת! (ביטול)".
- **הצ׳ק שלך**: סוג (כישרון/תובנה/סיפור בלעדי/אחר), לפקודת, שם המפגש, על מה נטעם, חודש מועדף, צרכים → "הצ׳ק נחתם!" + מייל לצוות.

## 5. חוגגות חודש טוב

- המפגש של החודש העברי הנוכחי (לפי לוח ירושלים); אם אין – הבא בתאריך; אם אין בכלל – "יפורסם בקרוב".
- ילידת החודש: "את מבעלות השמחה החודש!" + **צוות הנושא** (הצטרפות/יציאה). אחרת: "חוגגות את ילידות X".
- פרטי המפגש (תאריך עברי, שעה, מקום, נושא) + "אני באה לחגוג" ⇄ "מגיעה! (ביטול)" (מושבת ללא תאריך / מלא).
- "מה מחכה לנו במפגש": אקורדיון מהסדר-יום (שעה, כותרת, פירוט, שאלות לדיון). "מפגשים קודמים" – ארכיון.
- תזכורת למייל 7 ימים לפני לילידות החודש שסימנו "להזכיר לי" (cron יומי 06:00 UTC).
